# Same Bro Poster - Privacy Policy

Same Bro Poster is a private tool used only by the owner of the Same Bro channel (@samebrochannel) to upload its own videos to its own YouTube and Instagram accounts.

It does not collect, store, sell or share any data about other people. The only access it uses is permission to upload videos to the owner's own accounts. Access tokens are stored as encrypted GitHub secrets and are never shared.
